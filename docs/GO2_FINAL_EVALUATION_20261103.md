## 可直接运行的 Play 命令

在有图形桌面的训练主机终端运行，打开MuJoCo原生窗口，显示指令速度与实际速度箭头：

```bash
cd /home/yifeiy/ws_supermimic
PYTHONPATH=src OMP_NUM_THREADS=1 /home/yifeiy/miniconda3/envs/supermimic/bin/python scripts/play.py \
  --ckpt logs/phase3_training/go2_velocity_diagonal_slip_3072_2p5h_20261103/ckpt_0034000.pt \
  --num-envs 1 --device cuda:0 --viewer native \
  --vx 0.5 --vy 0 --yaw-rate 0 \
  --velocity-arrow --actual-velocity-arrow
```

将 `--vx 0.5` 改成 `--vx 0.3` 可看低速；侧移设 `--vx 0 --vy 0.3`，原地转向设 `--vx 0 --vy 0 --yaw-rate 0.4`。退出原生窗口可按Esc。若在没有图形显示的远程终端运行，可将viewer改为viser，通过其输出的浏览器地址查看。

也可直接执行运行目录中的 `play_final.sh`，默认前进0.5m/s。Play CLI帮助与脚本语法已验证；本次没有替用户打开持续运行的viewer。
